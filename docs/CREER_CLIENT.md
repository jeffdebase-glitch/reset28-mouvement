# Créer un client

1. Générer un identifiant aléatoire non évident, par exemple `c7f4a9d2`.
2. Copier `clients/DEMO/` vers `clients/<identifiant>/`.
3. Modifier uniquement `program.json` : prénom affiché, dates, minimum viable, semaines, séances et slugs existants.
4. Garder `index.html` identique au template.
5. Lancer `npm run check`.
6. Commit, publication, puis vérifier l'URL sur iPhone.

Règle : seulement le prénom ou prénom + initiale ; aucune donnée sensible.
