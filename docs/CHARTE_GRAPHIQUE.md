# Charte graphique

Référence : `RESET28_Questionnaire_prealable_redesign.pdf` du dossier maître.

- Fond blanc dominant.
- Bleu marine `#0D1734` pour titres et structure.
- Turquoise `#118783` et menthe `#E7F7F4` pour repères et cartes.
- Vert `#58BF16` uniquement en accent.
- Titres éditoriaux en sérif ; interface en police système.
- Cartes aérées, rayon 16-22 px, ombre discrète.
- Cible iPhone : texte >= 16 px pour le corps, zones tactiles >= 44 px, aucun débordement horizontal.
- Animations SVG 4:3, même avatar, boucle courte, sans texte incrusté.
