Fente arrière assistée

Une fente arrière avec une main sur un support pour sécuriser l'équilibre.

Lieu : maison / salleMatériel : support stableZones : cuisses, fessiers

Position et exécution

  1. Tiens légèrement un support stable.
  2. Recule un pied et descends verticalement.
  3. Pousse dans le pied avant pour revenir.

Les points qui comptent

  • Pas assez long pour rester stable.
  • Buste haut.
  • Appui principal sur la jambe avant.

Erreurs fréquentes

  • Tirer fort sur le support.
  • Poser le pied arrière sur une ligne trop étroite.

Respiration

Respire régulièrement, sans bloquer.

Quand arrêter

Arrête si tu ressens une douleur inhabituelle, vive ou qui augmente. Une gêne articulaire n'est pas un objectif d'entraînement.
