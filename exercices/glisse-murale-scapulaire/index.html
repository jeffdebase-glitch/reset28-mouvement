Tirage / dos · reprise

Glissé mural des bras

Faire glisser les avant-bras vers le haut d'un mur sans forcer l'amplitude.

Lieu : maison / salleMatériel : murZones : omoplates, épaules, haut du dos

Position et exécution

  1. Place les avant-bras au mur, coudes sous les épaules.
  2. Glisse les bras vers le haut.
  3. Redescends en gardant les épaules basses.

Les points qui comptent

  • Amplitude indolore.
  • Ne plaque pas le dos de force.
  • Mouvement lent.

Erreurs fréquentes

  • Hausser les épaules.
  • Forcer les poignets ou les coudes contre le mur.

Respiration

Respire régulièrement, sans bloquer.

Quand arrêter

Arrête si tu ressens une douleur inhabituelle, vive ou qui augmente. Une gêne articulaire n'est pas un objectif d'entraînement.
