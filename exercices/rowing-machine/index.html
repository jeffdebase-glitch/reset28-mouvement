Tirage / dos · débutant

Rowing assis machine

Tirer les poignées d'une machine vers le buste en restant stable.

Lieu : salleMatériel : machine rowingZones : haut du dos, grand dorsal, biceps

Position et exécution

  1. Règle l'assise et pose le buste si la machine a un appui.
  2. Tire les coudes vers l'arrière.
  3. Reviens jusqu'aux bras presque tendus sans te décoller.

Les points qui comptent

  • Poitrine stable.
  • Épaules basses.
  • Retour contrôlé.

Erreurs fréquentes

  • Se balancer.
  • Tirer uniquement avec les mains.

Respiration

Respire régulièrement, sans bloquer.

Quand arrêter

Arrête si tu ressens une douleur inhabituelle, vive ou qui augmente. Une gêne articulaire n'est pas un objectif d'entraînement.
